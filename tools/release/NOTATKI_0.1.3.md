Gotowe Koluszki w paczce.

## Zmiany
- `stacje\Koluszki\` – dopracowana stacja Koluszki: zobrazowanie z edytora, obwody gry, posterunki dla okna „SimRail”
  i katalog przebiegów gry. Wystarczy `stacje\uruchom_pulpit.cmd Koluszki` – bez zrzutu pulpitu i `nowa_stacja.cmd`.
- `CZYTAJ.md`, `INSTRUKCJA.md` – opis gotowych Koluszek (Kroki 6–7 można pominąć).
- Łączność: rozpoznawanie odcinków stacyjnych z numerem posterunku („3877_sk_…”) i szlakowych „69l11_it…”.

## Wymagania
Windows 10/11 x64, .NET Desktop Runtime 10.0 (≥ 10.0.13), Python 3 (skrypty stacji), SimRail + MelonLoader 0.7.x.

Instrukcja: `INSTRUKCJA.md` w paczce. Wersja rozwojowa.

Rysunek Koluszek pochodzi z gry SimRail – tylko do własnego użytku.
